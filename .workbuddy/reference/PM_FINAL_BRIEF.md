## 2. 登录引导弹窗最终规则（第四封，本次重点）

### 2.1 「第几天」口径
`D1` = 游客**首次产生学习数据的自然日**；按本地时间 00:00 日切计数。

### 2.2 触发日
| 日序 | 行为 |
|------|------|
| D1~D4 | 不弹 |
| **D5** | 弹 1 次 |
| D6 | 不弹 |
| **D7** | 弹 1 次 |
| **D8 及以后** | 只要**仍未登录**，**每天都弹 1 次**，直到用户登录账号为止 |
| 已登录 | 一律不弹 |

- **每天最多弹 1 次**（当日已弹则不再弹），按本地 00:00 日切重置。
- 用户选择「不再提示」后，**往后所有登录引导弹窗都不再弹**（永久生效，持久化）。

### 2.3 弹窗三个动作与状态
| 动作 | 效果 |
|------|------|
| `去登录` | 拉起华为账号授权 → 授权成功后按 Q11 触发**类型 B 合并选择弹窗** |
| `暂不` | **当日**不再弹；次日按上表规则继续弹 |
| `不再提示` | 持久化永久关闭标记 `neverPrompt = true`，**往后都不再弹** |

- 需持久化：`neverPrompt: boolean`、`lastPromptDate: 'YYYY-MM-DD'`，避免重复弹窗。
- **「不再提示」仅关闭类型 A 登录引导弹窗，不影响 Q11 / F-21 的合并选择弹窗**（登录成功后该弹窗仍按条件触发）。
- 授权失败可退回游客态，不阻断学习。

### 2.4 两类弹窗必须严格区分（工程师会照此实现）
- **类型 A = 登录引导**（F-22）：游客态、打开 App 时、按 D5/D7/D8+ 规则触发，目的是引导登录保存进度。
- **类型 B = 合并选择**（Q11 / F-21）：登录成功后、检测到游客进度时触发，目的是决定是否合并。
- 时序：**A → 用户点「去登录」→ 授权成功 → B**，不得合并成一个弹窗。

### 2.5 与 F-20 门禁的关系
弹窗内可显示「未登录期间已累计 X 天 / 掌握 Y 词 / 累计 Z 分钟」这类**引导性摘要**，它不是统计页、不构成 F-07/F-08 的进度展示，**F-20 游客态门禁依然成立**。请在 F-22 中明确写出这一条，避免与 F-20 冲突。
